# Hyundai Way – 30-Day Commitment Web App

มี 2 ไฟล์: `Code.gs` (หลังบ้าน) และ `Index.html` (หน้าเว็บ) ใช้เวลาติดตั้งประมาณ 10 นาที

## ติดตั้ง (ทำครั้งเดียว ด้วย Gmail ที่จะใช้ส่งอีเมล)

1. เปิด https://sheets.new สร้าง Google Sheet ใหม่ แล้วตั้งชื่อ เช่น `Hyundai Way Commitment`
2. ที่เมนูด้านบน ไปที่ **Extensions (ส่วนขยาย) → Apps Script**
3. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs` ของเราแทน
4. กด **＋ → HTML** ตั้งชื่อไฟล์ว่า `Index` (ต้องเป็นตัว I ใหญ่ ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาจากไฟล์ `Index.html`
5. กด 💾 Save
6. ที่ช่องเลือกฟังก์ชันด้านบน เลือก `setup` แล้วกด **Run**
   - Google จะขอสิทธิ์ ให้กด Review permissions แล้วเลือกบัญชี Gmail ของคุณ
   - ถ้าเจอหน้า "Google hasn't verified this app" ให้กด **Advanced → Go to … (unsafe)** แล้วกด **Allow** (เป็นแอปของเราเอง จึงปลอดภัย)
   - เสร็จแล้วใน Sheet จะมีแท็บ `Responses` และ `History` เพิ่มขึ้นมา
7. กด **Deploy → New deployment**
   - กดรูปเฟือง ⚙️ แล้วเลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้ว **Copy URL** ที่ลงท้ายด้วย `/exec`

## ใช้งานวันจริง

| ใช้ทำอะไร | ลิงก์ |
|---|---|
| ผู้เข้าร่วม (เปิดผ่าน QR Code) | `https://script.google.com/.../exec` |
| จอโปรเจกเตอร์หน้าห้อง | `https://script.google.com/.../exec?view=wall` |

- **จอโปรเจกเตอร์:** เปิดลิงก์ `?view=wall` แล้วกด F11 ให้เต็มจอ ที่มุมขวาบนจะมี **QR Code ให้สแกนอยู่แล้ว** การ์ดของแต่ละคนจะเด้งขึ้นบนจอภายในประมาณ 5 วินาทีหลังจากเขากด Submit
- ถ้าต้องการ QR Code ไว้พิมพ์หรือใส่ในสไลด์ ให้เอาลิงก์ `/exec` ไปสร้างที่เว็บสร้าง QR Code ทั่วไป
- **การแก้คำตอบ:** ผู้เข้าร่วมกด "✏️ แก้ไขคำตอบ" บนการ์ดของตัวเองได้ (ต้องเป็นมือถือเครื่องเดิม) คำตอบใหม่จะเขียนทับแถวเดิมในแท็บ `Responses` ส่วนแท็บ `History` จะเก็บทุกครั้งที่มีการส่งหรือแก้ไข

## โครงสร้างข้อมูลใน Google Sheet

- **Responses:** 1 แถวต่อ 1 คน เป็นคำตอบล่าสุด ประกอบด้วย ชื่อจริง, ชื่อเล่น, แผนก, Icon, Way 1–3 พร้อม Action, วันครบกำหนด, อีเมล, จำนวนครั้งที่แก้ไข
- **History:** บันทึกทุกครั้งที่ Submit (`new`) หรือแก้ไข (`edit`)

## ข้อควรรู้ (ใช้ Gmail ส่วนตัว)

- **โควตาส่งอีเมลของ Gmail ส่วนตัวคือประมาณ 100 ฉบับต่อวัน** สำหรับ 30 คนจึงเพียงพอ แต่ละคนส่งการ์ดเข้าอีเมลได้ไม่เกิน 5 ครั้ง
- อีเมลที่ส่งจาก Gmail ส่วนตัวไปยังอีเมลบริษัท **มีโอกาสตกไปอยู่ใน Junk ได้สูง** ในหน้าเว็บจึงมีข้อความเตือนไว้แล้ว และยังมีปุ่ม "📷 บันทึกการ์ดเป็นรูป" ให้ใช้เป็นทางสำรอง
- ด้านบนของหน้าเว็บจะมีแถบเทาข้อความ *"This application was created by a Google Apps Script user"* ซึ่งเป็นแถบของ Google สำหรับบัญชีส่วนตัว และเอาออกไม่ได้
- **ถ้าแก้โค้ดหลัง Deploy แล้ว** ต้องไปที่ Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy ทำแบบนี้แล้ว URL จะไม่เปลี่ยน QR Code เดิมจึงยังใช้ได้
- **ก่อนวันจริง ควรทดสอบ:** สแกนเองด้วยมือถือ 1–2 เครื่อง ลองส่งการ์ดเข้าอีเมลตัวเอง แล้วลบแถวทดสอบออกจาก Sheet
